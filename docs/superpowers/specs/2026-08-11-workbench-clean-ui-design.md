# AIwelink 工作台简洁化设计规范

## 目标

将登录后的工作台从“圆角卡片 + 玻璃层 + 装饰性容器”的视觉体系，迁移到与 AIwelink 动态主页一致的简洁工作界面。改造保留现有路由、权限、功能开关、API 和数据结构，只调整共享外壳与用户仪表盘的布局和呈现。

首批范围包括：

- 共享外壳：`AppLayout`、`AppSidebar`、`AppHeader`。
- 用户仪表盘：统计概览、平台用量、趋势和模型分布、最近使用、快捷操作。
- 共享视觉基础：工作台专用颜色、分隔线、面板、交互状态和响应式规则。

首批不重写 API 密钥、使用记录、充值、个人资料等业务页面内部结构。这些页面会立即获得新的侧边栏、顶栏和背景；其内部表格与表单可在后续 PR 中按同一规范迁移。

## 参考与取舍

### AIwelink 主页

保留主页已经建立的视觉信号：

- 浅色模式以真白、灰白、黑色文字为主，不使用大面积品牌色铺底。
- 深色模式以 `#050608` 黑色画布和高对比暖白文字为主。
- 暖金与粉色只用于关键数值、数据曲线、状态和焦点反馈。
- 依靠留白、排版和细线建立层级，不依靠悬浮卡片。

### new-api 新版

借鉴其工作台信息架构，而不照搬其视觉组件：

- 顶栏和侧栏职责明确，侧栏可收起。
- 页面标题、操作区和数据内容保持稳定位置。
- 密集数据优先使用表格、列表和连续工作区。
- 保留清楚的加载、空状态和筛选反馈。

new-api 概览页仍有较多 `rounded-2xl` 卡片和嵌套容器，AIwelink 不采用这一部分。

## 视觉系统

### 色彩

浅色模式：

- 画布：`#f7f7f7`，允许从 `#ffffff` 到 `#ededed` 的极浅背景层次。
- 主工作面：`#ffffff`。
- 主文字：`#101010`。
- 次文字：`#5f5f5f`。
- 弱文字：`#858585`。
- 分隔线：`#dedede`，重点分隔线 `#c8c8c8`。
- 粉色强调：`#d21f4b`。
- 金色强调：`#d39418`，保证白底可读性。

深色模式：

- 画布：`#050608`。
- 主工作面：`#0d1116`。
- 次工作面：`#171d24`，仅用于 hover、选中和输入区域。
- 主文字：`#f6f3eb`。
- 次文字：`#a5aab3`。
- 分隔线：`#303945`。
- 金色强调：`#ffc247`。
- 粉色强调：`#e2315c`。

业务语义色继续保留绿色成功、黄色警告和红色错误，但降低面积，只出现在状态点、文字和小型进度条中。

### 排版

- 界面字体继续沿用项目现有无衬线字体栈。
- 数值、版本、时间和紧凑标签优先使用等宽字体栈。
- 页面标题 18px/600；区块标题 13px/600；正文和控件 13px；辅助信息 11-12px。
- 字距保持 `0`，不通过负字距压缩内容。

### 几何与层级

- 页面区块不使用外层卡片框。
- 连续工作区使用 1px 分隔线划分内容。
- 固定面板和表单控件最大圆角为 6px。
- 菜单、弹窗等真正悬浮的表面可使用 6-8px 圆角和轻阴影。
- 头像、状态点、进度点可以保持圆形。
- 工作区不使用玻璃模糊、彩色网格、发光背景或装饰性粒子。

## 工作台外壳

### 侧边栏

- 展开宽度从 256px 缩减到 224px；收起宽度从 72px 缩减到 64px。
- 品牌区高度 56px，与顶栏对齐。Logo 使用 28px，不带发光和圆角底座。
- 导航项高度 36px，图标 17-18px，标签 13px。
- 默认态无背景；hover 只增加低对比底色。
- 当前项使用 2px 左侧强调线、较高文字权重和极浅强调底色，不使用胶囊框、描边和阴影。
- 分组标题使用 10-11px 等宽/大写风格，但字距为 0。
- 底部主题和收起操作保持原功能，改为分隔线之上的扁平操作行。
- 移动端沿用抽屉交互，遮罩保持，导航内容与桌面一致。

### 顶栏

- 高度从 64px 缩减到 56px。
- 移除 `.glass` 和 `backdrop-blur`，使用不透明工作面和底部分隔线。
- 桌面端保留页面标题与描述；移动端显示页面标题，避免只剩图标。
- 文档、模型广场、语言、公告和用户菜单保持现有权限条件。
- 余额改为紧凑的“Balance + 数值”文本组，不再放入圆角彩色容器。
- 用户入口移除渐变头像底座和外部胶囊 hover，保留头像、名称、角色和下拉箭头。

### 主内容

- 移除网格状 `bg-mesh-gradient` 背景。
- 内容最大宽度 1440px，在更宽屏幕居中。
- 桌面内边距 28-32px，平板 20-24px，移动端 16px。
- 页面切换和首次加载只允许 160-220ms 的淡入与 4-6px 位移；尊重 `prefers-reduced-motion`。

## 用户仪表盘

### 指标带

- 8 个现有指标继续全部展示，不删除业务信息。
- 桌面端为 4 列、2 行连续数据带；平板 2 列；移动端 1-2 列。
- 每个指标只包含小标签、主数值和一行辅助值。
- 不再使用彩色图标底块。图标改为 16px 单色线性图标，必要时仅主数值使用暖色。
- 指标之间用水平/垂直分隔线，不使用独立卡片边框和阴影。

### 平台用量

- 从“外层卡片内嵌平台卡片”改为开放式列表。
- 每个平台为一行或一列数据区域，展示平台、今日消费、请求、Token 和配额进度。
- 日/周/月配额使用 2px 线性进度条；禁用、即将耗尽和正常状态通过语义色文字与进度线表达。
- 平台较多时保持现有聚合逻辑，不改变数据计算。

### 分析区

- 日期范围、粒度和刷新操作组成一条紧凑工具栏。
- Token 趋势占主要宽度，模型分布和模型明细占次要宽度；大屏约为 58/42，小屏纵向堆叠。
- 图表不放进独立圆角卡片，只在标题区与图表区之间使用分隔线。
- 图表配色采用暖金主序列、粉色次序列和中性灰辅助序列，浅色模式使用加深后的金色。
- 模型明细使用紧凑表格，数字右对齐，行 hover 使用工作台次表面色。

### 最近使用与快捷操作

- 最近使用占大屏 2/3，快捷操作占 1/3；移动端依次堆叠。
- 最近使用改为分隔线列表，保留模型、Token、费用、状态和时间信息。
- 快捷操作改为文字命令列表：图标、标题、简短说明、右箭头；不再使用独立圆角操作块。
- “查看全部”作为区块标题右侧的文本操作，不使用大按钮。

## 状态与交互

- 加载状态使用与最终布局相同尺寸的线性 skeleton，避免内容跳动。
- 空状态在原区块内部居中，保留现有说明，不增加装饰插画。
- API 错误继续沿用现有日志和页面行为，本次不更改请求重试策略。
- hover、focus、active 必须可区分；键盘焦点使用 2px 暖色外环。
- 所有图标按钮保留 `aria-label` 或 title，正文对比度满足 WCAG AA。

## 组件边界

- `AppLayout.vue`：只负责工作台外壳、宽度和内容容器。
- `AppSidebar.vue`：保留导航生成、权限、功能开关和滚动恢复，只改变结构类名与视觉状态。
- `AppHeader.vue`：保留全部条件渲染和用户菜单行为，只调整层级与控件呈现。
- `UserDashboardStats.vue`：负责指标带和平台用量列表。
- `UserDashboardCharts.vue`：负责分析工具栏、趋势、模型分布和模型表格。
- `UserDashboardRecentUsage.vue`：负责最近使用列表与空/加载状态。
- `UserDashboardQuickActions.vue`：负责命令列表和路由跳转。
- `style.css` / `theme.css`：提供共享工作台 token 与基础类，不全局改变业务卡片，避免一次 PR 波及所有页面。

## 数据流与兼容性

- `DashboardView.vue` 继续并行加载统计、趋势、模型、最近使用和平台配额。
- 组件 props、emit 事件和路由地址保持兼容。
- 简单模式、管理员个人区、功能开关和自定义菜单继续使用现有逻辑。
- 图表仍使用 Chart.js / vue-chartjs，不引入新的图表库。
- 不新增后端接口、数据库迁移、环境变量或部署步骤。

## 测试与验收

自动化测试：

- 增加工作台视觉契约测试，验证外壳不再使用 mesh/glass，侧栏活动态不再使用阴影胶囊，仪表盘不再依赖 `.card` 容器。
- 保留并运行现有 Dashboard、AppSidebar 和主题 token 测试。
- 运行 `pnpm run typecheck`、`pnpm run lint:check` 和 `pnpm run build`。

浏览器验收：

- 桌面浅色 1440x900、桌面深色 1440x900、移动端 390x844。
- 检查侧栏展开/收起、移动抽屉、主题切换、用户菜单和仪表盘刷新。
- 检查长模型名、空数据、加载状态、平台配额较多时无溢出。
- 将生产截图与静态概念图对比，检查布局、排版、色彩、分隔线、圆角、响应式和控件状态。

## 明确不做

- 不把主页粒子/连杆动画放入工作台。
- 不重写后端和仪表盘 API。
- 不在本 PR 全量迁移所有业务页面内部卡片。
- 不引入新的 UI 框架、图标库或动画库。
- 不增加营销文案、虚构指标或新的业务入口。
