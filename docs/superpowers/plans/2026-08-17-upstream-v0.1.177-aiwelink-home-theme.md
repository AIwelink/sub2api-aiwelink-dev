# Sub2API v0.1.177 AIWeLink 首页与主题同步实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在最新 `origin/aiwelink-dev` 上合入 Sub2API `v0.1.177`，保留 AIWeLink 注册/referral/发布能力，并选择性恢复应用首页与红/金双主题，不带回 workbench 控制台结构。

**Tech Stack:** Git, Go 1.26.x, Vue 3, TypeScript, Tailwind CSS, Vitest, Bash, GitHub Actions.
